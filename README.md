## Assignment Requirements
The assignment required creating a webpage with the following:
- Basic information (name and AltSchool ID).
- A biography section.
- Reasons for joining the AltSchool program.
- Goals for the School of Engineering.
- A fragment identifier feature to enable scrolling back to the top.
- File named `index.html` inside a folder, without CSS.

The webpage is built using pure HTML, adhering to the "Strictly without CSS" requirement.
